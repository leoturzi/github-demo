# Git & GitHub — demo interactiva

Una presentación interactiva, hecha en un solo archivo HTML, que explica qué son **Git** y **GitHub** y cómo se usan, de lo más básico a lo colaborativo. En lugar de diapositivas estáticas, cada tema incluye una pequeña simulación con la que se puede jugar.

▶ **Verla online:** https://leoturzi.github.io/github-demo/

## Finalidad

Mostrar, de forma visual y práctica, el recorrido completo de un proyecto: primero **trabajando solo y de forma ordenada con Git** (en tu computadora) y después **colaborando en equipo con GitHub** (en la nube).

Fue desarrollada como trabajo grupal de **Programación II (UAI)**.

## Temas

| # | Tema | Qué se muestra |
|---|------|----------------|
| 1 | **Qué es Git** | Control de versiones, repositorio y commits |
| 2 | **Commits** | Las tres áreas de Git: working directory, staging y repositorio |
| 3 | **Branches y merge** | Trabajar en ramas paralelas, unirlas y resolver conflictos |
| 4 | **GitHub** | Repositorio local vs. remoto: `push`, `pull` y diferencia entre Git y GitHub |
| 5 | **Pull Requests** | Fork, cambios, revisión de código y merge |
| 6 | **Issues y Projects** | Organización de tareas con un tablero kanban |
| 7 | **Seguridad y cierre** | Buenas prácticas y un quiz final |
| 8 | **Tu turno** | Muro con el avatar de cada persona que hizo su primer Pull Request |

## Cómo usarla

- Abrí [`index.html`](index.html) en cualquier navegador moderno. No requiere instalación ni conexión a internet.
- Navegá entre temas con las pestañas de arriba o con las flechas del teclado <kbd>←</kbd> y <kbd>→</kbd>.
- Cada pantalla tiene botones y elementos interactivos: probá los comandos, arrastrá las tarjetas del tablero y respondé el quiz.

## Instructivo

¿Primera vez con Git? Seguí el [instructivo paso a paso](instructivo.md): instalar Git, loguearte a GitHub desde la terminal, hacer un fork y abrir tu primer Pull Request.
